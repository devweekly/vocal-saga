## Reddit post 页主帖不翻译 —— 双根因修复（扩展 27ea1bf / 服务端 e102d73）

用户报障 r/ExperiencedDevs 帖子翻译失败（评论区双语正常、主帖纯英文）。
诊断路径：线上缓存 /article/739（2.3MB 双语 HTML）→ 281 个标记块全在评论区、
主帖 shreddit-post 区间 0 个 → 扩展端预标记时文章根选错。

**根因 1：hostPattern 全等 bug。** `hostMatches` 对非通配 pattern 做全等比较，
`'reddit.com'` ≠ `'www.reddit.com'` → **整份 Reddit 规则从未生效**。
修复：`'*.reddit.com'`（通配形式同时匹配裸域与子域）。
排查提示：测试里 `shouldSkipBySiteRules(shreddit-comment)` 返回 false 是
第一个线索 —— 规则命中却返回 false 说明匹配层就断了。

**根因 2：文章根被选进评论区。** Reddit 把每条评论渲染成
`<details role="article">`，扩展端 Layer 1 的 `'[role="article"]'` 优先级
高于 `'main'`；chooseBestRoot 评分偏爱文本密集、按钮少的评论容器
（main 因按钮过多被扣分）→ 根=评论子树 → 主帖在根外。
修复：`articleRootSelector: 'main#main-content'`（Layer 0 最高优先级）。

**skipSelectors 语义警告**：`shouldSkipBySiteRules` 用 `closest()` 匹配 +
walker REJECT = 整棵子树剪枝。往里放 `shreddit-comment` 这种大容器等于放弃
整个评论区（它从未生效纯属根因 1 侥幸）。已删除并留防回归注释。

**测试双向验证方法论**：先跑绿 → 临时去掉修复 → 必须转红 → 恢复。
第一版真实 fixture 测试去修复后仍绿（fixture 太小、评分没拉开），
补合成 DOM（评论长文本 + main 按钮重罚 -15/-10/-8）后才真红。
另一个坑：合成评论文本 5440 字符超过 MAX_TEXT_LENGTH(3072) 被跳过，
调到 ~2700 才行。

**服务端缺口**：lib/translate/contentHelper.ts 没有 Layer 0
（articleRootSelector）实现，findArticleRoot 直接走 selectBestRoot。
当前不触发（/fanyi/page 根选择在扩展端；服务端直访 Reddit 拿反爬空壳），
已记录 CROSS_PROJECT_SYNC.md §2.5。若服务端未来支持登录态抓取必须先接入。

**验证**：扩展端 1000 测试全过；服务端 357 测试全过 + typecheck 零报错。
扩展端修复需重新构建加载才能生效（用户浏览器里是旧构建）。
