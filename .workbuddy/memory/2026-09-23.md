## 清除陈旧 git index.lock

`git add .` 报 `Unable to create '.git/index.lock': File exists`。

排障流程（可复用）：
1. `pgrep -lx git` → 空。注意要用 `-x` 精确匹配进程名；宽泛的 `ps aux | grep git` 会命中
   VS Code 的 Code Helper、cumora 的 claude 进程、WorkBuddy sandbox-cli（路径里都含 "git"），
   全是噪声。
2. 确认锁文件 mtime 距今多久（本次 07:37 创建，08:00 发现，23 分钟）。
3. 无 git 进程 + 锁残留 → 陈旧锁，`rm -f .git/index.lock` 安全。

这是本仓库第二次遇到（上次 9/19 残留超 24h）。根因大概率是 IDE / 编辑器后台的 git 集成
持有锁后被中断。单纯删锁不需要重启 IDE。
