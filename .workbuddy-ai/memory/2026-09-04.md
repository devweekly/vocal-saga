## P0-1 extractJsonContainer 静默丢 block（已修）
- 文件：`lib/translate/service/shared.ts`
- 原因：用 `lastIndexOf(close)` 切容器边界。JSON 被 max_tokens 截断时，切片
  得到"合法但不完整"的片段，`JSON.parse` 成功 → jsonrepair 的截断修复根本没被调用 →
  尾部若干 block 静默丢失。防御函数反而打败了它要辅助的库。
- 修法：改为配平扫描 `scanBalancedEnd()`，跟踪字符串状态与嵌套深度；
  扫到末尾仍未配平返回 `s.length - 1`，把残缺片段交给 jsonrepair 补齐。
- 测试：`tests/sharedJsonUtils.test.ts`（17 例，4 例可证伪）

## P0-2 SSRF 重定向绕过（已修）
- 文件：`lib/translate/urlFetcher.ts`
- 原因：`redirect: 'follow'` 只暴露链尾 `response.url`，入口的 `assertPublicUrl`
  只校验链首。公网页 302 → `http://169.254.169.254/` 可整条绕过（连端口白名单一起）。
- 修法：`redirect: 'manual'` + 自写 `fetchWithGuardedRedirects()`，逐跳解析
  `Location`（相对地址按当前跳 URL 解析）并校验；上限 MAX_REDIRECTS=5。
- 测试 seam：把布尔开关 `skipSsrfGuard` 换成可注入的 `ssrfGuard?: (url) => void`
  —— 只能替换校验实现，不能关闭校验本身。
- 测试：`tests/urlFetcher.test.ts`（18 例，8 例可证伪）

## P0-3 concurrency 参数是装饰（已修）
- 文件：`lib/translate/concurrency.ts`（新增）+ `lib/translate/pipeline.ts`
- 原因：`chunks.map(worker)` + `Promise.all` = 全并发，`concurrency` 只进日志。
- 修法：固定大小 worker 池 `runWithConcurrency(items, limit, worker)`。
- 测试：`tests/concurrency.test.ts`（13 例）+ `tests/pipelineConcurrency.test.ts`
  （管线真路径：deepseek ≤4、openrouter =1）

## 踩坑
- `chunkBuilder` 的 `TARGET_TOKENS` 是 **10000**（AGENTS.md 写的 1000 已过时）
- 构造测试长文时：单段 textContent 必须 < `MAX_TEXT_LENGTH`(3072)，否则整段被丢弃；
  段落之间也不能高度重复，否则被样板文本检测判为噪声。
  可用 300 段 × ~1100 字符 ≈ 10 个 chunk。

## 全局扩展层（把站点规则泛化到任意网站）

用户问"这些特定网站规则能否 apply 到其它网站"。现状：SiteRule 按 `hostPattern`
精确/通配匹配，只注册了 13 个站；新站必须手动加规则。通用层
`applyGlobalNoiseFromUrl` 已对**所有**站跑 aside/dialog/fixed 底栏/分享栏。
用户选了「全局扩展层」方案。

实现：新增 `lib/translate/rules/globalRules.ts` 导出 `GLOBAL_RULE: SiteRule`
（`hostPattern: '*'`，仅 `removeSelectors`，无 displayCss），收拢**高置信跨站**噪声：
- OneTrust：`#onetrust-consent-sdk` / `#onetrust-pc-sdk` / `section#ot-fltr-modal` /
  `[id*="onetrust" i]` / `[class*="onetrust" i]`（被成千上万站点共用，一条覆盖一片）
- 通用 Cookie：`[id*="cookie-consent" i]` / `[class*="cookie-banner" i]` /
  `[class*="cookie-notice" i]` / `#sp_message_container` / `iframe[id*="sp_message" i]` /
  `[id*="cookielaw" i]`
- 通用 modal 遮罩：`[role="dialog"]` / `.modal-backdrop` /
  `[class*="modal-backdrop" i]` / `[class*="modal__backdrop" i]` /
  `[class*="modal-overlay" i]` / `[id*="modal-overlay" i]`
- 订阅弹窗（收窄）：`form[action*="newsletter" i]` / `[class*="newsletter-popup" i]` /
  `[class*="newsletter-modal" i]` / `[class*="newsletter-overlay" i]`

`displayRules.ts` 的 `applySiteDisplayRules` 改造为：空 URL 直接原样返回；否则
`rules = [GLOBAL_RULE, ...(matched ? [matched.siteRule] : [])]`，循环 apply
（全局先、站点后，站点 displayCss 后追加优先级更高）。GLOBAL_RULE **不进 RULES 数组**，
避免 first-match 把站点专属规则顶掉。`hostPattern: '*'` 仅为语义标记。

取舍（重要）：**不放** `[class*="paywall" i]` 裸付费墙 class（可能包裹正文）、
不放宽泛的 `[class*="newsletter" i]`（可能命中正文含 "newsletter" 字样的普通元素）——
这些留给站点专属规则，避免误删正文。

测试：displayRules.test.ts 加 4 例（未知域名也清 OneTrust/Cookie/modal；全球+站点叠加；
正文含 "newsletter" 不被误删）。相关 4 文件共 36 例全绿，typecheck + build:lib 通过。
⚠️ 仍需 `npm run deploy:cf` 才上线。
