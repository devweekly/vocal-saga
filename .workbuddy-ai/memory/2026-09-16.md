## article/676 固定浮动的 AWS banner

反馈：`https://s.sunxiunan.com/article/676`（源站
`https://aws.amazon.com/blogs/machine-learning/how-ninth-wave-built-ai-powered-open-finance-onboarding-on-amazon-bedrock/`）
正文上方永远悬着一条 "AWS Blogs / Home / Blogs / Editions"。

根因：AWS Blogs 用两个 `position:fixed; z-index:5000` 浮层：
- `#m-subnav`（`data-testid="subnav-desktop"`，CSS `.rgsn_359d1dc8`：`top:16px; --subnav-voffset:125px`）
- `[data-testid="feedback-button"]`（右下角固定反馈按钮）

修复：新增 `lib/translate/rules/awsblogs-rules.ts`（`hostPattern: 'aws.amazon.com'`），
`removeSelectors` 用稳定的 id / data-testid（AWS 类名是 hash 化的 `rgsn_*` / `rggn_*`，
会随发版变，不能依赖），并额外注入同选择器的 `displayCss` 兜底。
已注册进 `rules/index.ts` 的 RULES。

验证：线上 `/article/676` 返回
`<div data-fanyi-remove="true" id="m-subnav" ...>`，兜底 CSS 已注入，
`[data-fanyi-remove="true"]{display:none!important}` 规则在位。已部署。
