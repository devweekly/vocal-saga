Vocal Saga

OpenAI 兼容的 LLM 代理 + 网页翻译服务。支持 DeepSeek、OpenRouter、NVIDIA、Cloudflare AI 四个后端。

翻译页面（浏览器直访）

路径说明
/translate/<url>翻译页面（默认 DeepSeek，双语模式）
/force/<url>强制重新翻译，跳过 D1 缓存（限 1 次/分钟）
/openrt/<url>使用 OpenRouter 免费模型翻译
/nvd/<url>使用 NVIDIA kimi-k2.6 翻译
/nvd/deepseek/<url>使用 NVIDIA deepseek-v4-pro 翻译
/cf/<url>使用 Cloudflare AI (gpt-5-nano) 翻译
/s/<domain>/<path>简写域名翻译（如 /s/medium/article）
/original/<url>原始页面（不翻译）
/o/<url>/original 别名

Query params（可选）：source（默认 en）、target（默认 zh）、mode（bilingual | target）

历史翻译

路径说明
/最新一次翻译结果
/<id>D1 中第 N 次翻译结果

LLM 代理 API

方法路径Auth说明
POST/api/v1/chat/completions✓Chat Completions（OpenAI 兼容）
GET/api/v1/models✗可用模型列表
GET/api/hello?name=…✗健康检查

后端路由规则

根据请求中的 model 和 _backend 字段自动选择后端：

条件后端示例
_backend: "cloudflare"Cloudflare AIopenai/gpt-5-nano
_backend: "nvidia"NVIDIA Buildkimi-k2.6、deepseek-v4-pro
_backend: "openrouter"OpenRouteropenrouter/free
模型名含 /Cloudflare AIopenai/gpt-5-nano
模型名以 deepseek- 开头DeepSeekdeepseek-v4-flash
其他（默认）DeepSeek自动使用 deepseek-v4-flash

认证

/api/v1/chat/completions 需要 Authorization: Bearer <key> 认证。

翻译页面路由（/translate、/force 等）不需要认证。

使用示例

# 翻译网页（浏览器直接访问）
https://ss.dal.workers.dev/translate/example.com/article/path

# 强制重新翻译（跳过缓存）
https://ss.dal.workers.dev/force/example.com/article/path

# 使用 OpenRouter 免费模型
https://ss.dal.workers.dev/openrt/example.com/article/path

# 使用 NVIDIA kimi-k2.6
https://ss.dal.workers.dev/nvd/example.com/article/path

# 使用 NVIDIA deepseek-v4-pro
https://ss.dal.workers.dev/nvd/deepseek/example.com/article/path

# 使用 Cloudflare AI
https://ss.dal.workers.dev/cf/example.com/article/path

# LLM 代理 — DeepSeek
curl -X POST "/api/v1/chat/completions" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

# LLM 代理 — 指定 NVIDIA 后端
curl -X POST "/api/v1/chat/completions" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2.6",
    "_backend": "nvidia",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

术语表 API

方法路径说明
GET/api/glossary读取术语表
POST/api/glossary追加 user_terms
DELETE/api/glossary清空 user_terms
DELETE/api/glossary/:term删除指定 user_term（需 Auth）
POST/api/glossary/extract从文本抽取 document_terms（?merge=true 合并到 user）
PUT/api/glossary/document显式设置 document_terms
DELETE/api/glossary/document清空 document_terms（需 Auth）

已知限制

限制说明
仅 chat/completions不支持 /completions、/embeddings 等其他 OpenAI 端点
CF AI 不支持流式Cloudflare Workers AI /cf 路由降级为非流式响应
/force 限流每 IP 每分钟最多 1 次强制翻译
