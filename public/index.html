Express API

A simple Express.js API running on Netlify Functions.

Endpoints

  • GET /.netlify/functions/api/hello?name=YourName — greet by name
  • POST /.netlify/functions/api/echo — echo back JSON body

Try it

curl "/.netlify/functions/api/hello?name=Netlify"
curl -X POST "/.netlify/functions/api/echo" \
     -H "Content-Type: application/json" \
     -d '{"hello":"world"}'
