Vocal Saga

OpenAI 兼容的 LLM 透明代理，将请求转发到 Cloudflare AI 或 DeepSeek。

端点

方法路径说明
POST/api/v1/chat/completionsChat Completions（OpenAI 兼容）
GET/api/v1/models可用模型列表
GET/api/hello?name=…健康检查

后端路由规则

根据请求中的 model 字段自动选择后端：

模型名特征后端示例
包含 /Cloudflare AI@cf/meta/llama-3.1-8b-instruct、deepseek/deepseek-v4-pro
以 deepseek- 开头（白名单）DeepSeekdeepseek-v4-flash、deepseek-v4-pro
其他（默认）DeepSeek自动使用 deepseek-v4-flash

认证

/api/v1/chat/completions 需要 Authorization: Bearer <key> 认证。

使用示例

# Cloudflare AI — deepseek-v4-flash
curl -X POST "/api/v1/chat/completions" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek/deepseek-v4-flash",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

# DeepSeek 官方 — deepseek-v4-flash
curl -X POST "/api/v1/chat/completions" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

响应中会附带 _backend 字段，标识实际使用的后端（"cloudflare" 或 "deepseek"）。

已知限制

限制说明
模型列表硬编码/models 返回静态列表，不动态查询上游。
仅 chat/completions不支持 /completions、/embeddings 等其他 OpenAI 端点。
参数兼容性某些 OpenAI 参数（如 logprobs）上游可能不支持，直接透传会导致 400 错误。

环境变量

在 Netlify Dashboard 中配置以下环境变量：

变量说明必填
CLOUDFLARE_ACCOUNT_IDCloudflare 账户 ID使用 CF 模型时必填
CLOUDFLARE_API_TOKENCloudflare API Token（需 Workers AI 权限）使用 CF 模型时必填
DEEPSEEK_API_KEYDeepSeek API Key使用 DS 模型时必填
